# 📌 Sobre o repositório

Este repositório reúne todos os exercícios, atividades, desafios e projetos desenvolvidos durante as aulas da disciplina de **Linguagem de Programação (LPR)**.

O objetivo é documentar minha evolução na programação, praticando algoritmos, lógica, estruturas de dados e Programação Orientada a Objetos utilizando **C#** e **C++**.

Além de servir como material de estudo, este repositório funciona como um histórico da minha aprendizagem ao longo do curso.
